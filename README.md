# CS211 Project - 2048 and Luhn (MW, Group 99)
This repo has my two programs for the CS211 group project. They are separate programs and each one builds on its own.

- **game2048** - a 2048 game on a 5x5 board that runs in the console. You slide tiles up, down, left, or right and matching tiles combine. It keeps score, counts moves, and can save and load a game.
- **luhn** - checks if a 16 digit number passes the Luhn checksum. Passing just means the digits add up right, it doesn't mean it's a real card.
